# Polygon Perimeter Calculation with Functional Kotlin

## 📝 Description
This application calculates the total perimeter of a polygon (either convex or concave) based on the coordinates of its vertices. The project highlights the use of **idiomatic Kotlin functional programming** features, specifically the `zipWithNext` extension function, to process consecutive elements in a collection without manual indexing.

The program automatically ensures the polygon is "closed" by connecting the last provided vertex back to the first one before performing the calculation.

## 🚀 Key Features
* **Functional Processing**: Leverages `zipWithNext` to create pairs of consecutive vertices for distance calculation.
* **Geometric Logic**: Implements the Euclidean distance formula to find the length of each edge.
* **Closed Loop Automation**: Automatically appends the starting point to the end of the vertex list to complete the polygon circuit.

📐 Mathematical Approach

For every pair of consecutive points (P1​(x1​,y1​),P2​(x2​,y2​)) generated by zipWithNext, the distance d is calculated using:
d=(x2​−x1​)2+(y2​−y1​)2​

The final perimeter is the sum of all calculated distances d in the collection.
